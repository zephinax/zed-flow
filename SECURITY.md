# Security Policy

## Supported Versions

Security updates are applied to the latest stable release of ZedFlow.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

ZedFlow takes security seriously, especially given that it executes local scripts and interacts with system processes.

If you believe you have found a security vulnerability in ZedFlow:

1. **Do not** report the issue publicly on GitHub issues or discussions.
2. Please report the issue via GitHub's [Private Vulnerability Reporting](https://github.com/zephinax/zed-flow/security/advisories/new) or email the maintainer directly.
3. Provide detailed steps to reproduce the vulnerability, including sample scripts or environment parameters if applicable.

You will receive an acknowledgment within 48 hours, followed by an assessment and patch schedule. Thank you for helping keep ZedFlow and its users safe.
